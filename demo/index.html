stimulus_sheet · demos

HTML-first bottom-sheet for Stimulus.js. iOS-style half/full snap, drag-to-dismiss, portal-to-body, Hotwire-Native bridge. Built to survive Turbo navigations and TurboNative WKWebView.

  1. 01 — Basic sheet
    Single sheet, open from a trigger, click backdrop to close.
  2. 02 — Half & full
    Open half by default, drag up (or tap) to expand to full.
  3. 03 — Action list
    Sectioned .ss-section-title + .ss-item rows.
  4. 04 — Multiple sheets
    Two independent sheets, opened by id.
  5. 05 — Imperative API
    StimulusSheet.open(id) / close / toggle from arbitrary JS.
  6. 06 — Portal to body
    Sheet inside a transformed container, portaled out so it sits above its host.
  7. 07 — Events log
    Watch sheet:opened / sheet:closed / sheet:snap.
  8. 08 — Non-dismissable
    Backdrop click ignored — sheet only closes via an explicit action.
  9. 09 — Form in a sheet
    Submit a form, close on submit.
  10. 10 — Hotwire-Native bridge
    Native action sheet on a TurboNative shell; falls back to web on a browser.

Run with npm run dev. Each demo loads the IIFE bundle from ../dist/ so make sure you've run npm run build:lib at least once.
