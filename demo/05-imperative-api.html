05 — Imperative API

Triggers are convenient but optional. StimulusSheet.open(id) drives any registered sheet from arbitrary JS — handy from a Turbo Stream callback, a third-party widget, or the console.

Try in the console: StimulusSheet.open('imperativeSheet')

Imperative sheet

Driven from window.StimulusSheet.open/close/toggle. The same hook is used by Turbo Stream callbacks in your Rails app — see RAILS.md.
